# Contact 页面截图对齐设计说明

> 日期：2026-08-11
> 分支：`feat/public-site`
> 参考：用户提供的三张 Contact 页面截图

## 1. 目标与范围

将 `/[locale]/site/contact` 从当前两张并列简卡改为截图中的三段纵向联系信息区块：

1. `FOR CREATOR / 01`：应募说明、LINE 咨询入口、招募合作方资料。
2. `FOR COMPANION / 02`：制作与运营合作说明、制作合作方资料。
3. `FOR CLIENT / 03`：法人业务说明、邮箱入口、业务联系资料。

截图中的公司名称、代表人、成立年份与地点、业务内容、地址、邮箱及营业时间均原样写入。此次不新增后台数据源、表单或外部接口。

## 2. 页面结构

页面顶部沿用官网子页标题结构：青绿色 `CONTACT` eyebrow 与大号日文标题 `お問い合わせ`。标题下方按截图顺序放置三个带 corner ticks 的大型蓝图框。

每个区块在桌面端采用左右双栏：

- 左栏约 40%，包含编号 eyebrow、明朝体标题、说明文字和可选 CTA。
- 右栏约 60%，包含合作方标签、可选 Chiron 文字标志，以及逐行资料表。
- 表格使用浅灰 panel 底、1px 发丝线、青绿色字段名和深色正文。

小于 `lg` 断点后改为单栏：左侧介绍在上，资料表在下；表格标签列维持可读的最小宽度，长地址允许自然换行。页面不产生横向滚动。

## 4. 组件与数据边界

- `src/app/[locale]/site/contact/page.tsx`：只负责读取翻译内容并按顺序组合三个区块。
- `src/components/site/ContactSection.tsx`：负责区块双栏布局、CTA、合作方标题和资料表。
- `src/lib/site/contact.ts`：声明资料行类型，并提供把 `next-intl` 原始内容校验为页面数据的轻量转换函数。
- `messages/{ja,zh,en}.json`：保存三段内容、资料行及 CTA 文案。

Chiron 标志以黑底白字的文字标识实现，不裁切或放大截图中的低分辨率图块，不新增第三方素材请求。

## 5. 交互与主题

- 邮箱 CTA 和表内邮箱均使用 `mailto:business@echoamp.jp`。
- LINE CTA 暂时保持现有应募入口 `RECRUIT_HREF`，直到提供正式 LINE URL。
- 深浅主题继续使用现有 `site-*` 设计 token；浅色主题重点对齐参考截图，深色主题保持等价对比度和可读性。
- 所有 CTA 保留键盘焦点和语义化链接行为。

## 6. 测试与验收

测试先行：

1. 为 contact 内容转换函数新增测试，先验证三段顺序、编号、资料行数量、关键原文和链接语义。
2. 观察测试因缺少实现而失败后，再实现数据转换、组件和页面。
3. 运行完整单测、三语 parity、裸汉字检查、样式 token 检查及生产构建。
4. 在 `http://localhost:3099/ja/site/contact` 验证桌面视口与移动视口：三段顺序、双栏/单栏切换、无横向溢出、邮件链接和控制台错误。

验收标准：页面信息与三张截图逐项一致；桌面构图接近截图；移动端内容完整可读；三语页面均可渲染；现有官网导航、主题与构建门禁不回归。
