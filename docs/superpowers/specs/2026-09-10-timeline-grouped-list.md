# 战略时间轴：分组列表与时间轴联动

用户已批准紧凑分组列表，并明确选择“点击时间轴节点，定位并展开对应行”。

- 默认打开列表；保留接下来 30 天、完整时间轴和进度曲线入口。
- 列表按逾期、即将到期、进行中、计划中、已完成分组。空分组不显示，已完成默认折叠；仅筛选已完成时直接展示。
- 四列：节点、负责人、目标日期、时间状态。类型和优先级作为节点副信息。描述、开始日期、完成日期、详情入口和删除操作在行展开区展示。
- 采用共享 CSS grid 对齐标题与行；小屏变为两列信息布局。交互采用原生按钮，不把按钮嵌套在按钮或链接中。
- 日期按 zh/en/ja 本地化、UTC 日戳解释，当年省略年份，跨年保留年份。
- 顶部紧凑时间轴表示目标日期和今天。节点按状态着色，配编号与可读标签；重叠节点合并为可展开的选择组。
- 点击时间轴节点设置选择项，展开所属分组与行，滚动到行并移动键盘焦点。手动展开列表也同步选中时间轴。
- 完成时间沿用已发布的 completion 逻辑，不重新引入完成任务的倒计时。
- 现有筛选同时作用于时间轴和列表；不修改 API 或数据库。

验证：分组顺序、完成优先、日期跨年与时区、相同日期与空数据；组件语义和联动；中文、英文、日文及窄屏布局；完整单测、类型、文案、样式和构建。
